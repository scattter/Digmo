# Digmo Web + 小程序路线图

## 阶段划分

### M1（估值后端）

- 完成 API 与估值任务。
- Web/小程序先使用固定基金列表读取。

### M2（Web MVP）

- 双主视图：`组合视图` + `基金平铺`。
- 全部组合与单组合基金明细。
- 组合管理：创建、重命名、删除；组合内基金增删改。
- 组合类型：自由组合（FREE）与按比例组合（RATIO）。
- 手动更新入口与最近更新时间提示。
- 涨幅排序单按钮三态（默认/降序/升序）。
- 基金详情（估值、更新时间、置信度）。
- Web UI/UX 组件化重构（`ui-ux-pro-max` + `shadcn-ui`）：
  - 双模式：专业（默认）/极简，本地持久化。
  - 首页与详情页全量组件化，统一设计 token 与交互规范。
  - 详见：`prds/005-web-ui-ux-refactor-shadcn.md`。

### M3（小程序 MVP）

- 自选基金卡片列表。
- 单基金详情页。
- 下拉刷新与错误降级提示。

### M4（观测与体验优化）

- API 响应耗时与错误率看板。
- 回测误差监控。
- Web 与小程序交互优化。

## 统一规则

1. 端侧只消费 `packages/shared` DTO，不做字段自行推断。
2. 估值页面固定显示免责声明。
3. 日期与时间统一 ISO8601，页面按本地时区展示。
