# Digmo 组合 + 平铺双主视图 PRD

## 背景

原有 Web 仅支持单层基金关注列表，无法按用户组合进行分组管理，也缺少统一的组合收益视图。需要升级为“组合视图 + 基金平铺”双主视图，同时保留手动更新节奏。

## 目标

1. 全局支持两种主视图：
   - 基金平铺：查看所有组合内基金。
   - 组合视图：按组合维度管理与查看收益。
2. 支持完整组合管理：
   - 创建、重命名、删除组合。
   - 组合内新增、更新、删除基金。
3. 支持两类组合：
   - 自由组合（FREE）：不展示比例字段。
   - 按比例组合（RATIO）：展示并校验计划比例与实际比例。
4. 组合卡片将“组合总收益 + 组合总涨幅”合并为一个字段：
   - `组合总收益: 金额/比例`（示例：`+1,256.30 / +3.28%`）。
5. 恢复并保留“手动更新”入口：
   - 手动刷新后展示“最近手动更新时间”。
6. 基金平铺排序升级为单按钮三态“涨幅排序”：
   - 默认排序 -> 降序（↓）-> 升序（↑）-> 默认排序。
7. 单组合页新增“比例达成 + 今日预估”分析区：
   - 左侧比例达成图（RATIO 专属）：展示每只基金计划比例与实际比例。
   - 右侧今日预估列表：展示 `基金名称 + 金额/百分比`，支持三态排序（默认/降序/升序）。
8. 单组合页支持组合内基金手动拖拽重排序（桌面+移动）并持久化。
9. 盘中估算涨跌口径修订：
   - 交易日：优先使用“当日接口估值”结果（包含交易时段与非交易时段）。
   - 非交易日：盘中估算涨跌固定为 `0`。
   - 禁止展示上一交易日估算值。

## 范围

### In Scope

1. Web 主页信息架构改造为双主视图。
2. 组合、组合基金、基金平铺后端 API。
3. SQLite 组合化数据存储与旧 watchlist 迁移。
4. 基金平铺模式支持：
   - 去重汇总（dedup）。
   - 按组合展开（expanded）。
5. 手动更新与状态提示。
6. 单组合页分析区（比例达成 + 今日预估）及排序交互。
7. 单组合页基金拖拽重排序（含后端持久化）。
8. 交易日/非交易日盘中估算涨跌口径修订。

### Out of Scope

1. 小程序端同步改造。
2. 多用户隔离与账户体系。
3. 自动轮询刷新策略（仍以手动更新为主）。

## 核心交互规则

1. 主视图切换：
   - `组合视图`
   - `基金平铺`
2. 创建组合入口仅在 `组合视图` 展示。
3. `组合视图` 默认子视图为 `全部组合`，展示组合卡片平铺。
4. `基金平铺` 顶部包含：
   - 去重汇总/按组合展开切换。
   - 单按钮三态“涨幅排序”（含箭头标识）。
5. 手动更新按钮全局可见，点击后刷新：
   - 组合列表
   - 基金平铺数据
   - 当前选中组合基金列表
6. 单组合页（`selectedPortfolioId !== "all"`）在基金列表上方展示分析区：
   - 左侧“比例达成”：
     - FREE：不展示比例图，仅提示自由组合无计划比例。
     - RATIO：每只基金展示“计划比例柱 + 实际比例柱”。
     - 实际比例低于计划或超计划不超过 10%：灰色。
     - 实际比例超计划超过 15%：实际比例柱为低饱和警示色。
   - 右侧“今日预估”：
     - 行格式：`基金名称 + 金额/百分比`。
     - 排序：默认（手动顺序）-> 降序（↓）-> 升序（↑）-> 默认。
7. 单组合页支持拖拽排序：
   - 拖拽手柄触发，避免与输入框/按钮冲突。
   - 桌面鼠标与移动触摸均可操作。
   - 拖拽后先前端乐观更新，再调用后端持久化；失败则回滚并提示错误。

## 业务规则

1. RATIO 组合新增/更新基金时：
   - `plannedRatio` 必须在 `[0, 1]`。
   - 组合内计划比例总和必须 `<= 1`。
2. 实际比例：
   - `actualRatio = 当前基金持仓金额 / 组合总金额`。
3. 收益字段：
   - `totalProfitAmount = Σ(holdingAmount * totalChangePct)`
   - `totalProfitPct = totalAmount > 0 ? totalProfitAmount / totalAmount : 0`
   - `totalProfitDisplay = 金额/比例`。
4. 涨跌趋势色：
   - `estimateChangePct > 0.0001` -> UP
   - `< -0.0001` -> DOWN
   - 其余 -> FLAT
5. 组合内基金默认顺序规则：
   - 默认按用户手动顺序展示（优先级高于按涨幅排序）。
   - 新增基金默认追加到组合末尾。
6. 盘中估算涨跌规则：
   - 交易日：仅使用当日实时估值；若接口不可用或返回非当日数据，则值为 `0`。
   - 非交易日：值固定为 `0`。

## 数据存储与迁移

### 新表

1. `user_portfolio`
2. `user_fund_state`
3. `user_portfolio_fund`
   - 新增列 `display_order INTEGER`（组合内显示顺序）

### 迁移策略

1. 若旧 `user_watchlist_fund` 有数据且新组合表为空：
   - 自动创建 `默认组合`（FREE）。
   - 将旧数据迁入新结构。
2. 迁移要求幂等，不重复迁移。
3. 旧表保留，不再作为主读写模型。
4. `display_order` 迁移补齐策略：
   - 对历史数据按 `created_at DESC, rowid DESC` 回填顺序值，保持“新加在前”的历史直觉。

## 验收标准

1. 组合视图：
   - 仅组合视图显示创建组合入口。
   - 全部组合卡片展示 `组合总金额`、`组合总收益(金额/比例)`、`当日预估涨幅`。
2. 基金平铺：
   - 支持去重/展开切换。
   - 单按钮三态涨幅排序可循环切换，UI 文案和箭头正确。
3. 手动更新：
   - 可手动触发全量刷新。
   - 成功后展示最近手动更新时间。
4. RATIO 组合：
   - 计划比例超过 100% 被拒绝（400）。
   - FREE 不展示比例字段，RATIO 展示计划/实际比例。
5. 迁移：
   - 旧 watchlist 数据自动进入默认组合，重复启动不重复导入。
6. 单组合页分析区：
   - 基金列表上方展示“比例达成 + 今日预估”双栏区块。
   - RATIO 组合出现计划/实际比例柱；FREE 不出现比例柱。
   - 今日预估列表支持默认/降序/升序三态排序。
7. 拖拽排序：
   - 单组合页支持桌面+移动拖拽重排。
   - 页面刷新后顺序保持不变。
   - 拖拽失败时顺序回滚并显示错误提示。
8. 盘中估算涨跌口径：
   - 交易日不展示上一交易日估算值。
   - 非交易日估算涨跌为 `0`。
