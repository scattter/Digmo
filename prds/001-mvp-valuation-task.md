# Digmo MVP：估值任务模块

## 目标

首期实现可持续运行的估值任务模块，提供股票型/指数型场外基金的盘中估值快照能力，并通过 API 输出统一结果。

## 范围

### In Scope

1. MCP 聚合数据接入（持仓、净值、基金概况、市场行情）。
2. 估值计算：`INDEX_TRACKING` + `BETA_PROXY`。
3. 调度：交易时段 30 秒，非交易时段 30 分钟。
4. 幂等处理：`fund_code + estimate_time_bucket` 去重。
5. 缓存：基金估值、批量查询、行情缓存。
6. 状态与日志：任务运行状态、失败分布。

### Out of Scope

1. 交易与账户体系。
2. macOS 小组件。
3. 多数据源仲裁。

## 关键数据流

1. 采集层从数据源拉取基金元信息与行情。
2. 估值引擎基于最新净值 + 行情代理计算盘中估值。
3. 置信度引擎按数据新鲜度、模型拟合、回测误差计算评分。
4. 快照写入存储并刷新 Redis 缓存。
5. API 输出标准化响应。

## 验收

1. 单基金估值接口可在 200ms 内返回缓存数据。
2. 批量接口支持一次 50 只基金。
3. 任务状态接口返回最近 20 次运行统计。
4. 估值响应包含置信度和免责声明。
