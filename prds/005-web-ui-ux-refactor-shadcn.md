# Digmo Web UI/UX 组件化重构 PRD（ui-ux-pro-max + shadcn-ui）

> 更新时间：2026-03-10（与当前前端实现保持一致）

## 背景

Web 端已从早期“双主视图 + 局部面板”演进为“侧边导航 + 多视图分层”结构，同时接入了组合页的决策与操作能力。为避免“页面行为与文档定义”再次脱节，本 PRD 记录当前已落地的布局、交互和验收口径。

## 目标

1. 固化当前 Web IA（信息架构）与组件边界，保证后续迭代在同一基线推进。
2. 在不改变核心业务语义的前提下，提升组合管理与日常操作效率。
3. 统一桌面与移动端导航体验，减少认知跳转。
4. 保持 shadcn 组件体系下的可访问性与一致交互反馈。

## 已锁定决策（当前基线）

1. 信息架构与导航
   - 页面入口统一为 `/?view=<view>`，支持：`overview`、`portfolios`、`funds`、`analysis`。
   - 桌面端使用左侧导航 + 顶部面包屑，移动端使用抽屉导航（Sheet）。
   - `analysis` 视图保留入口但仅显示占位说明：“V2 视图已下线”。

2. 总览页（overview）
   - 顶部使用三块卡片：`总资产净值`、`今日估算盈亏`、`快捷操作（添加基金/新建组合）`。
   - 视觉使用渐变与强调色卡片，数值型信息保持高可读（大字号 + 等宽数字）。

3. 基金列表页（funds）
   - 保留 `去重汇总 / 按组合展开` 切换。
   - 保留涨跌排序单按钮轮转（默认/降序/升序）。
   - 列表操作集中在卡片内部，刷新入口就近放置。

4. 组合页（portfolios）结构
   - “全部组合”与“单组合详情”共享同一路由状态，通过 `selectedPortfolioId` 切换。
   - 全部组合状态：展示可拖拽组合标签栏 + 组合概览表。
   - 单组合状态：展示分析面板 + 决策摘要卡片 + 持仓表。

5. 单组合“决策与操作”入口
   - 卡片提供三个动作：`更新`（生成今日建议）、`管理文档`、`历史`。
   - “管理文档”打开 Dialog，承载策略文档上传/查看/编辑/保存。
   - “历史”打开 Dialog，按时间倒序查看历史建议并支持展开详情。

6. 策略文档面板（DailyDecisionPanel）
   - 支持上传 `.md/.markdown/.txt`，并根据后缀自动识别 `TEXT/MARKDOWN`。
   - 支持折叠/展开文档正文；展开后可直接编辑并保存。
   - 显示当前版本号与源文件名（若存在）。

7. 持仓列表与更新交互
   - 持仓列表支持拖拽排序、表头吸顶/左右列吸附、行内操作下拉菜单。
   - `更新基金`弹窗提供三种模式：`直接更新` / `加仓` / `减仓`。
   - `加仓/减仓`模式支持可选绑定“今日建议动作”。

8. 样式 Token 与组件底座
   - 在全局主题变量中补齐 `card / card-foreground / popover / popover-foreground`。
   - 新增并启用 `sheet`、`dropdown-menu`、`avatar`、`alert`、`breadcrumb` 等 shadcn 组件作为布局与交互底座。

9. 反馈与状态
   - 异步动作统一通过 Toast 反馈（成功/失败）。
   - 页面状态提示聚焦在“手动更新状态 + 刷新时间”，避免重复提示区块。

## 范围

### In Scope

1. 首页四视图导航与布局容器（桌面/移动）。
2. 全部组合、单组合、基金平铺的当前交互路径。
3. 单组合决策入口、文档管理弹窗、建议历史弹窗。
4. shadcn 组件化重构及样式 token 对齐。

### Out of Scope

1. 小程序 UI 同步改造。
2. 后端核心估值算法变更。
3. 账户偏好跨端同步。

## 技术与实现约束

1. 前端以 `@digmo/shared` DTO 为唯一契约来源，不自行扩展字段语义。
2. 组件栈：`shadcn-ui` + `radix-ui` + `lucide-react` + `sonner`。
3. 表单与输入校验：`react-hook-form + zod`。
4. 可访问性：
   - icon-only 按钮必须提供 `aria-label` 或 `sr-only` 文案。
   - 异步提交按钮需具备 loading/disabled 状态，防止重复操作。

## 验收标准

1. 导航可通过 URL `view` 参数稳定切换四个视图。
2. 桌面端侧栏与移动端抽屉导航均可访问同一视图集合。
3. 组合页在“全部组合 / 单组合”之间可顺畅切换，且拖拽排序可用。
4. 单组合页可完成“管理文档 → 生成建议 → 查看历史”闭环入口访问。
5. 持仓更新弹窗中 `直接更新 / 加仓 / 减仓` 三模式均可提交；加减仓可选绑定建议动作。
6. `analysis` 视图展示“V2 视图已下线”占位信息，不再出现 V1/V2 对比面板。
7. 质量门禁：
   - `pnpm --filter @digmo/web typecheck` 通过。
   - `pnpm --filter @digmo/web build` 通过。

## 风险与缓解

1. 新旧页面结构并存导致认知混乱。
   - 缓解：固定 `view` 参数与导航文案，统一入口语义。
2. 单组合页信息密度提升后操作误触风险增加。
   - 缓解：关键动作集中在弹窗/二次交互中，列表行操作使用下拉菜单隔离。
3. UI 文案和 PRD 再次漂移。
   - 缓解：每次结构级改动必须同步更新本 PRD 与对应专项 PRD（如 `007/009`）。
