# UI/UX Refactor Proposal: Portfolio Dashboard Optimization

## 目标 (Goal)
- **减少层级**: 减少用户触达基金组合和基金列表的点击成本。
- **一站式展示**: 在单页展示尽可能多的信息（总览 + 组合 + 基金）。
- **移动端优化**: 适配移动端布局，提升操作便捷性。

## 现有问题 (Current Issues)
- **路径过长**: 首页仅展示总额 -> 点击侧边栏 -> 点击组合 -> 查看详情。
- **信息分散**: 首页信息量太少，大部分时间在跳转。
- **移动端交互**: 侧边栏在移动端通常折叠，需要额外点击展开。

## 方案草稿 (Layout Drafts)

### 方案 A: 聚合仪表盘 (Aggregated Dashboard) - **推荐**
**核心思路**: 将“所有组合”作为首页的核心组件，通过卡片列表快速切换上下文。

#### 布局结构
1.  **顶部 (Global Stats)**:
    -   保留现有的总资产、今日收益卡片。
    -   移动端优化：左右滑动或紧凑排列。
2.  **中部 (Portfolio Selector)**:
    -   **横向滚动列表 (Mobile) / 网格 (Desktop)**: 展示所有组合的缩略卡片。
    -   **卡片内容**: 组合名称、总资产、当日收益率。
    -   **交互**: 点击卡片选中该组合，下方内容区域即时刷新。
    -   **默认选中**: "全部组合" (Aggregate View)。
3.  **下部 (Details Area)**:
    -   **动态内容**:
        -   若选中“全部”: 展示去重后的所有基金列表 (`FlatFundsTable`)。
        -   若选中“特定组合”: 展示该组合的详情、分析图表、操作建议 (`PortfolioFundsTable` + `AnalysisPanel` + `DecisionPanel`)。

#### 优点
-   **零跳转**: 首页即是所有功能的入口。
-   **高信息密度**: 组合概览与基金详情同屏展示。
-   **直观**: 卡片式导航比纯文本 Tab 更具吸引力且易于点击。

---

### 方案 B: 标签页导航 (Tabbed Navigation)
**核心思路**: 使用标准的标签页系统组织内容。

#### 布局结构
1.  **顶部**: 全局资产概览。
2.  **中部 (Tabs)**:
    -   [总览] [稳健组合] [激进组合] ... [ + ]
3.  **内容区域**:
    -   **总览 Tab**: 所有基金列表。
    -   **组合 Tab**: 组合详情 + 基金列表。

#### 优点
-   节省垂直空间。
-   符合常见后台管理系统习惯。

#### 缺点
-   Tab 数量多时在移动端需要横向滚动，且 Tab 标题通常只显示名称，无法展示“该组合今日收益”等动态信息（除非自定义 Tab 渲染）。
-   相比方案 A，视觉冲击力较弱。

---

### 方案 C: 侧边栏增强 (Sidebar Enhanced) - 仅桌面端优化
**核心思路**: 保持侧边栏，但使其更智能。

#### 布局结构
-   **侧边栏**: 默认展开“基金组合”菜单，列出所有组合名称。
-   **首页**: 变成“仪表盘”，包含所有组合的摘要卡片。点击卡片跳转到对应路由。

#### 缺点
-   移动端依然需要点击汉堡菜单才能看到侧边栏，无法解决移动端触达成本高的问题。

## 移动端适配细节 (Mobile Adaptation)

针对方案 A 的具体优化：

1.  **组合卡片**:
    -   使用 **横向滚动容器 (Horizontal Scroll Snap)**。
    -   当前选中的组合卡片高亮显示。
2.  **表格视图**:
    -   基金列表在移动端可能过宽。
    -   建议：在移动端将表格行转换为 **卡片列表 (Card List)** 或 **折叠面板 (Accordion)**，只展示核心字段（名称、金额、收益），点击展开查看详情。
3.  **操作按钮**:
    -   关键操作（如“添加基金”、“一键调仓”）固定在底部悬浮栏或顶部导航栏，避免被长列表淹没。

## 视觉风格建议 (Visual Style)

-   **卡片化**: 保持现有的 Ant Design Card 风格，增加阴影层次感。
-   **紧凑模式**: 减少移动端的 Padding/Margin，增加信息密度。
-   **数据可视化**: 在组合卡片上增加微型趋势图 (Sparklines)，让收益走势一目了然。

## 推荐实施路径

1.  **重构 `FundDashboard`**: 移除路由视图切换，改为内部状态切换 (`selectedPortfolioId`)。
2.  **改造 `PortfolioOverviewTable`**: 使其支持“选择模式” (Selection Mode)，作为顶部的导航组件。
3.  **整合 `FlatFundsTable` 和 `PortfolioFundsTable`**: 根据选择状态动态渲染。
